# 变更：网易云音乐功能增强

## 原因
根据用户反馈，需要完善网易云音乐的核心功能，包括：
1. 实现真实的歌曲列表展示（至少使用5个API接口）
2. 完善播放功能和专辑旋转动画
3. 实现播放模式切换和歌词滚动显示
4. 添加搜索功能
5. 创建API模块统一管理接口

## 变更内容
- 创建API模块，统一管理所有音乐相关的API接口
- 实现真实的歌曲列表，使用提供的API接口获取数据
- 完善音乐播放器功能，包括播放控制、专辑旋转动画
- 实现歌词系统，支持歌词滚动和同步显示
- 添加搜索功能，支持歌曲和歌手搜索
- 优化播放模式切换（单曲循环、列表播放、随机播放）

## 影响
- **受影响的规范**：API管理、音乐播放、歌词显示、搜索功能
- **受影响的代码**：
    - `src/api/` - 新建API模块目录
    - `src/views/home.vue` - 更新首页实现真实数据展示
    - `src/views/discover.vue` - 创建发现音乐页面
    - `src/views/playlist.vue` - 创建播放列表页面
    - `src/views/rank.vue` - 创建排行榜页面
    - `src/components/MusicPlayer.vue` - 完善播放器功能
    - `src/components/LyricsDisplay.vue` - 新建歌词显示组件
    - `src/components/SearchBox.vue` - 完善搜索组件
