# 变更：在首页添加可点击跳转的轮播图

## 原因
当前首页需要更丰富的视觉展示方式，通过轮播图展示热门歌曲封面，提升用户体验，增强视觉吸引力。

## 变更内容
- **添加**: 在首页顶部添加轮播图组件，展示热门歌曲封面
- **添加**: 轮播图支持自动轮播和手动切换功能
- **添加**: 点击轮播图可直接播放对应歌曲
- **修改**: 移除首页所有硬编码的示例数据，改用API数据
- **添加**: 新增轮播图API接口调用

## 影响
- **受影响的规范**: 首页展示、音乐播放
- **受影响的代码**:
  - `src/views/home.vue`: 添加轮播图组件，移除示例数据
  - `src/api/index.js`: 添加轮播图相关API接口
  - `src/api/music.js`: 添加轮播图数据格式化和获取服务
  - `src/stores/player.js`: 可能需要扩展播放功能支持轮播图点击播放
